# עשהאל — דף קמפיין

דף נחיתה לגיוס תרומות ליישוב עשהאל, בעברית ובאנגלית (נפתח תמיד באנגלית; עברית דרך המתג או בקישור ישיר `?lang=he`).
אתר סטטי בלי שלב בנייה, מתארח ב-GitHub Pages.

## תצוגה מקדימה
```bash
python3 -m http.server 8000   # ואז http://localhost:8000
```

## מבנה
| קובץ | תפקיד |
|------|-------|
| `index.html` | הדף |
| `accessibility.html` | הצהרת נגישות |
| `assets/css/site.css` | העיצוב (טוקנים בראש הקובץ, כולל מצב כהה) |
| `assets/js/head.js` | נטען לפני הציור: שפה ומחלקת `js` |
| `assets/js/main.js` | מתג שפה, הסרטון, מונה הקמפיין, אנימציות |
| `assets/captions/*.vtt` | כתוביות לסרטון (נטענות כשהסרטון מתארח באתר) |
| `assets/images/` | סטילס מסרטון הקמפיין, הלוגו ותמונת השיתוף `og.jpg` |
| `drafts/` | הטיוטה הקודמת (לא מתפרסמת) |

## הרעיון העיצובי
צורה אחת: קשת הגבעה מהלוגו. היא הכיפה הגדולה בראש הדף, המסגרת של כל תמונה, החלק העליון של הכפתורים והתבליטים.
מבנה הדף: פתיחה ← חלום של דורות ← אנחנו כאן כדי להישאר ← הסרטון ← תרומה ← פוטר.
פונטים: Rubik לכותרות, Assistant לטקסט.

## עדיין להשלים ⚠️
- **מונה הקמפיין:** ב-`assets/js/main.js` למלא `CAMPAIGN = { goal, raised, donors }`. כל עוד הערכים `null` המונה מוסתר.
- **פס הטיוטה:** למחוק את `<div class="draft">` ב-`index.html` אחרי אישור הוועדה.
- **מספר עמותה** בפוטר, ופרטי **רכז/ת נגישות** ב-`accessibility.html`.
- **הסרטון:** כרגע נפתח מ-Google Drive. כדי לקבל כתוביות, להעלות MP4 ל-`assets/video/` ולמלא `data-video-src` על `#video`.
- **דומיין:** אם עוברים לדומיין משלכם, להוסיף קובץ `CNAME` ולעדכן את `og:url` / `og:image`.

## אבטחה
- CSP ב-`<meta>` (ב-Pages אי אפשר להגדיר כותרות HTTP): רק קבצים מהאתר עצמו, ונגן Google Drive.
- אין JS בתוך ה-HTML. פיקסל אנליטיקס יתווסף כקובץ ב-`assets/js/`, ויש להרחיב את ה-CSP בהתאם.
- הפונטים מתארחים באתר (`assets/fonts/`). התרומה עצמה מתבצעת בדף של תקציבית (`tak.co.il`), והאתר לא נוגע בפרטי תשלום.
